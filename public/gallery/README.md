# Gallery Photos Folder

Drop your fest and event photos directly into this folder:
`public/gallery/`

### How to use:
1. **Option A (Quickest)**: Replace the existing sample photos (`gallery-1.jpg`, `gallery-2.jpg`, ..., `gallery-10.jpg`) with your own photos keeping the same names.
2. **Option B (Custom)**: Drop your images here with any filename (e.g. `dance.jpg`, `concert.jpg`, `hackathon.png`) and list them in `src/app/components/GallerySection.tsx`.

### Supported Formats:
- `.jpg` / `.jpeg`
- `.png`
- `.webp`
